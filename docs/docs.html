系统要求

  • 操作系统：支持 Windows 10/11（推荐）、macOS 10.15+ 与 Linux，三大平台原生运行。
  • 运行环境：Python 3.9 及以上版本，推荐使用 uv 进行极速依赖管理。
  • FFmpeg：需单独安装并加入系统 PATH，应用启动时自动检测路径，也可在「设置」页面手动指定。
  • 硬件加速：可选配备 GPU（NVIDIA / Intel / AMD / Apple），用于编码加速；建议内存 4GB 以上。

源码运行

源码运行与部署流程（开发者 / 高级用户）：

# 1. 克隆仓库
git clone --recursive https://github.com/Fairy-Oracle-Sanctuary/Easy-FFmpeg.git
cd Easy-FFmpeg

# 2. 创建并激活虚拟环境
uv venv
.venv\Scripts\activate        # Windows
source .venv/bin/activate     # Unix/macOS

# 3. 安装依赖
uv pip install -r requirements.txt
uv pip install -r requirements-win.txt   # Windows 额外依赖
uv pip install -r requirements-mac.txt   # macOS 额外依赖

# 4. 确保 ffmpeg 已安装并加入 PATH
#    或在应用「设置」页面手动指定路径

# 5. 运行应用
python Easy-FFmpeg.py
