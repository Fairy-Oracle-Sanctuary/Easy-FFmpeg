核心功能

覆盖视频处理全流程的强大工具集

任务队列与批量处理

可视化任务卡片实时显示进度、速度、码率与预估大小。SQLite 持久化存储，支持批量添加、重试、取消、删除，拖放文件即可添加任务。

高级编码参数

编码器选择（软件 / 硬件加速）、CRF / 码率质量控制、分辨率与帧率调整、音频编码、自定义 FFmpeg 命令模板，参数块按需勾选。

12 种常用工具

音频提取、视频截图、GIF 制作、视频剪切、格式转换、图片压缩、视频拼接、媒体信息、MS Store 徽标、字幕处理、音量归一化、速度调整。

跨平台支持

原生支持 Windows 10/11、macOS 10.15+ 与 Linux 三大平台，FFmpeg 路径自动检测，开箱即用。

硬件加速

支持 NVIDIA NVENC、Intel QSV、AMD AMF、Apple VideoToolbox 等硬件编码器，大幅缩短编码时间。

现代化界面

Fluent 设计语言，Windows 11 Mica 效果，深色 / 浅色主题快捷切换，系统托盘集成，内置更新检查与多语言支持。
